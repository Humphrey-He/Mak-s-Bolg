## 一、系统架构

### 1.1 整体架构


## 三、实体模型

### 3.1 ArticleStatus 枚举

```csharp
public enum ArticleStatus
{
    Draft = 0,      // 草稿（未发布）
    Published = 1,  // 已发布
    Archived = 2    // 归档
}
```

### 3.2 Article 实体

```csharp
public class Article
{
    public int Id { get; set; }

    // 内容
    public string Title { get; set; }           // 标题
    public string Slug { get; set; }           // URL slug（唯一）
    public string Description { get; set; }    // 摘要
    public string Content { get; set; }         // 正文（草稿内容）

    // 元数据
    public string Tag { get; set; }            // 标签: "Go / Cache"
    public int ReadTimeMinutes { get; set; }   // 阅读时间（分钟，自动计算）
    public bool IsTop { get; set; }            // 置顶
    public bool IsFeatured { get; set; }       // 精选

    // 状态
    public ArticleStatus Status { get; set; } // 草稿/已发布/归档

    // Git 追踪
    public string FilePath { get; set; }       // content/posts/{slug}.mdx
    public string? LastCommitSha { get; set; } // 最后一次 Git 提交

    // 时间
    public DateTime? PublishedAt { get; set; } // 发布时间
    public DateTime CreatedAt { get; set; }
    public DateTime UpdatedAt { get; set; }

    // 关系
    public int? CoverImageId { get; set; }
    public Media? CoverImage { get; set; }
}
```

### 3.3 PublishJob 实体

```csharp
public class PublishJob
{
    public int Id { get; set; }
    public int ArticleId { get; set; }
    public Article Article { get; set; }

    public string Status { get; set; }
    // Pending / Running / Succeeded / Failed / Retrying

    // 结果
    public string? ErrorMessage { get; set; }
    public string? CommitSha { get; set; }

    // 时间
    public DateTime CreatedAt { get; set; }
    public DateTime? StartedAt { get; set; }
    public DateTime? FinishedAt { get; set; }

    // 重试
    public int RetryCount { get; set; }
}
```

## 五、Git 操作设计

### 5.1 发布流程

```
用户点击发布
    ↓
创建 PublishJob (status: Pending)
    ↓
后台 Worker 拾取任务
    ↓
[1] git pull origin main  (拉取最新)
    ↓
[2] 生成/更新 MDX 文件
    ↓
[3] Rust validate (可选校验)
    ↓
[4] git add → git commit → git push
    ↓
[5] 更新 PublishJob (status: Succeeded, commitSha: xxx)
    ↓
GitHub Webhook 触发 Cloudflare Pages 构建
```

### 5.2 失败处理

| 场景 | 处理方式 |
|-----|---------|
| Git pull 冲突 | retry 1次，再失败标记 Failed |
| MDX 生成失败 | 标记 Failed，不执行 push |
| Git push 失败 | retry 3次，间隔 5s/10s/30s |
| 全部失败 | 标记 Failed，记录错误信息，数据库状态不变 |

### 5.3 Git 安全

- 使用 GitHub Personal Access Token（最小权限：repo）
- Token 存储于环境变量
- Commit message 格式：`docs: {action} article {title}`

## 七、安全设计

### 7.1 认证安全

| 措施 | 说明 |
|-----|-----|
| 密码存储 | BCrypt（cost factor 12） |
| JWT | HS256，7天过期 |
| 登录失败锁定 | 5次失败锁定 15 分钟 |
| Refresh Token | HttpOnly Cookie 存储 |

### 7.2 API 安全

| 措施 | 说明 |
|-----|-----|
| 速率限制 | 100 req/min（未认证），1000 req/min（已认证） |
| CORS | 仅允许管理后台域名 |
| SQL 注入 | EF Core 参数化查询 |
| XSS | 内容转义 |

### 7.3 MDX 安全

| 措施 | 说明 |
|-----|-----|
| JSX 限制 | 仅允许预定义组件 |
| script 禁止 | 过滤 `<script>` 标签 |
| import 限制 | 禁止动态 import |
| 危险 HTML | 过滤 `onclick`/`onerror` 等事件属性 |

### 7.4 上传安全

| 措施 | 说明 |
|-----|-----|
| 文件类型白名单 | jpg/png/gif/webp/svg |
| 文件大小限制 | 5MB |
| 图片 EXIF 清理 | 移除 EXIF 元数据 |
| 文件名重命名 | UUID 避免冲突 |

## 八、Rust CLI 设计

### 8.1 命令列表

```bash
# 内容校验
content-cli validate content/posts/wtinylfu-algorithm.mdx

# 搜索索引构建
content-cli index content/posts --out public/search-index.json

# Sitemap 生成
content-cli sitemap content/posts --base-url https://shuhong.icu --out public/sitemap.xml

# RSS 生成
content-cli rss content/posts --config feed.yaml --out public/feed.xml
```

### 8.2 校验规则

| 错误码 | 说明 |
|-------|-----|
| E001 | title 为空或超过 100 字符 |
| E002 | slug 格式不正确 |
| E003 | date 格式不正确（YYYY-MM-DD） |
| E004 | tag 格式不正确 |
| E005 | content 为空 |
| W001 | 描述超过 200 字符 |
| W002 | 缺少代码块 |
| W003 | LaTeX 语法疑似错误 |
