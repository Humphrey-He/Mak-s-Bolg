# 博客自研 CMS 技术设计文档

## 一、系统架构

### 1.1 整体架构

```
┌────────────────────────────────────────────────────────────────┐
│                         前台博客                                │
│              Next.js + Cloudflare Pages                        │
│                    (静态站点，仅消费)                            │
└────────────────────────────────────────────────────────────────┘
                              ↑ HTTP / Git Webhook
┌────────────────────────────────────────────────────────────────┐
│                       内容发布层                                 │
│  ┌─────────────────┐              ┌─────────────────┐        │
│  │   C# CMS 后台    │ ──────────→ │  Rust 内容引擎   │        │
│  │  ASP.NET Core   │              │   (内容处理)     │        │
│  │  管理/认证/CRUD │              │  解析/校验/索引  │        │
│  └────────┬────────┘              └────────┬────────┘        │
│           │                                │                  │
│           ↓                                ↓                  │
│  ┌─────────────────────────────────────────────────┐        │
│  │              content/posts/*.mdx                 │        │
│  │                    (Git 仓库)                    │        │
│  └─────────────────────────────────────────────────┘        │
└────────────────────────────────────────────────────────────────┘
```

### 1.2 技术选型

#### C# CMS 后台

| 组件 | 技术 | 版本 | 说明 |
|-----|-----|-----|-----|
| 框架 | ASP.NET Core | 8.0 | 最小 API |
| ORM | EF Core | 8.0 | SQLite 开发，PostgreSQL 生产 |
| 认证 | JWT Bearer | - | Cookie + Token 双模式 |
| 前端 | React + Ant Design | 18.x | 管理后台 UI |
| API文档 | Swagger | - | 接口文档 |

#### Rust 内容引擎

| 组件 | 技术 | 版本 | 说明 |
|-----|-----|-----|-----|
| 框架 | Axum | 0.7 | Web 框架 |
| Markdown | comrak | - | MDX 解析 |
| 搜索 | tantivy | - | 全文搜索索引 |

## 二、C# CMS 模块设计

```

├── BlogCMS.Api/              # API 层
│   ├── Controllers/          # 控制器
│   ├── Middleware/          # 中间件

│   ├── Data/               # EF Core
│   └── Repositories/       # 仓储
└── BlogCMS.Admin/           # React 管理后台
    ├── src/
    └── public/
```

### 2.2 核心实体

```csharp
// 管理员
public class Admin
{
    public int Id { get; set; }
    public string Username { get; set; }
    public string PasswordHash { get; set; }
    public string Email { get; set; }
    public DateTime CreatedAt { get; set; }
}

// 文章
public class Article
{
    public int Id { get; set; }
    public string Title { get; set; }
    public string Slug { get; set; }      // URL 标识
    public string Description { get; set; } // 摘要
    public string Content { get; set; }     // MDX 正文
    public string Tag { get; set; }        // 标签
    public string ReadTime { get; set; }   // 阅读时间
    public bool IsTop { get; set; }        // 置顶
    public bool IsPublished { get; set; }  // 发布状态
    public DateTime CreatedAt { get; set; }
    public DateTime UpdatedAt { get; set; }
}

// 标签
public class Tag
{
    public int Id { get; set; }
    public string Name { get; set; }
    public string Slug { get; set; }
}
```

## 三、Rust 内容引擎模块设计

### 3.1 项目结构

```
src/
├── content-engine/           # 核心引擎库
│   ├── parser/             # Markdown/MDX 解析
│   ├── validator/          # 内容校验
│   └── search/             # 搜索索引
├── content-cli/             # CLI 工具
│   └── main.rs
└── content-api/            # HTTP API (可选)
    └── server.rs
```

### 3.2 核心功能

#### 内容解析器

```rust
pub struct ParsedArticle {
    pub title: String,
    pub slug: String,
    pub description: String,
    pub date: String,
    pub tag: String,
    pub read_time: String,
    pub content: String,
    pub frontmatter: Frontmatter,
}

pub fn parse_mdx(content: &str) -> Result<ParsedArticle>
```

#### 内容校验器

```rust
pub struct ValidationResult {
    pub is_valid: bool,
    pub errors: Vec<ValidationError>,
    pub warnings: Vec<ValidationWarning>,
}

pub fn validate_article(article: &ParsedArticle) -> ValidationResult
```

校验规则：
- title 必填，最大 100 字符
- slug 唯一，格式校验
- date 格式必须为 YYYY-MM-DD
- content 不能为空

#### 搜索索引

```rust
pub struct SearchIndex {
    index: tantivy::Index,
}

impl SearchIndex {
    pub fn add_article(&mut self, article: &ParsedArticle)
    pub fn search(&self, query: &str, limit: usize) -> Vec<SearchResult>
}
```

## 五、安全设计

### 5.1 认证方案

| 方案 | 适用场景 |
|-----|---------|
| JWT Bearer Token | API 认证 |
| HttpOnly Cookie | Web 前端会话 |

### 5.2 密码安全

- BCrypt 哈希存储
- 密码强度要求：8位以上，含大小写和数字

### 5.3 API 安全

- 所有管理接口需要认证
- 请求频率限制
- CORS 配置

### 5.4 内容安全

- 敏感操作记录审计日志
- Git 操作记录所有变更

| 环境 | 方案 |

```bash

ConnectionStrings__DefaultConnection=PostgreSQL://...
Jwt__Secret=your-256-bit-secret
Jwt__ExpiryDays=7

# Rust Engine
DATABASE_URL=postgresql://...
GITHUB_TOKEN=ghp_xxx
```
