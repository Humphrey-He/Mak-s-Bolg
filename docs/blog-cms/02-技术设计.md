# 博客自研 CMS 技术设计文档

## 一、系统架构

### 1.1 整体架构

```
┌────────────────────────────────────────────────────────────────────────┐
│                           前台博客                                      │
│              Next.js + Cloudflare Pages (静态)                          │
│                        (仅消费 API/Git)                                 │
└────────────────────────────────────────────────────────────────────────┘
                              ↑
┌────────────────────────────────────────────────────────────────────────┐
│                         内容发布层                                       │
│                                                                        │
│  ┌─────────────────┐              ┌─────────────────┐                │
│  │   C# CMS 后台    │ ─────/→     │  Rust 内容引擎   │                │
│  │  ASP.NET Core   │              │   (内容处理)     │                │
│  │  管理/认证/CRUD │              │  解析/校验/索引  │                │
│  └────────┬────────┘              └────────┬────────┘                │
│           │                                │                          │
│           ↓                                ↓                          │
│  ┌─────────────────────────────────────────────────────┐            │
│  │                   MDX 文件 + Git                      │            │
│  │        content/posts/*.mdx + content/projects/*.mdx    │            │
│  └─────────────────────────────────────────────────────┘            │
└────────────────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────────────────┐
│                         第三方服务                                     │
│         GitHub (内容存储) / Tina Cloud (可选保留)                      │
└────────────────────────────────────────────────────────────────────────┘
```

### 2.2 实体模型

```csharp
// 管理员
public class Admin
{
    public int Id { get; set; }
    public string Username { get; set; }        // 登录名
    public string DisplayName { get; set; }     // 显示名称
    public string PasswordHash { get; set; }    // BCrypt 哈希
    public string Email { get; set; }            // 邮箱
    public string Role { get; set; }            // 角色: admin/editor
    public DateTime CreatedAt { get; set; }
    public DateTime? LastLoginAt { get; set; }
}

// 文章
public class Article
{
    public int Id { get; set; }
    public string Title { get; set; }           // 标题
    public string Slug { get; set; }            // URL slug
    public string Description { get; set; }      // 摘要
    public string Content { get; set; }          // MDX 正文
    public string Tag { get; set; }             // 标签: "Go / Cache"
    public string ReadTime { get; set; }         // 阅读时间: "15 min"
    public bool IsTop { get; set; }             // 置顶
    public bool IsFeatured { get; set; }        // 精选
    public bool IsPublished { get; set; }       // 发布状态
    public DateTime? PublishedAt { get; set; }   // 发布时间
    public DateTime CreatedAt { get; set; }
    public DateTime UpdatedAt { get; set; }

    // 关系
    public int? CoverImageId { get; set; }      // 封面图
    public Media? CoverImage { get; set; }
    public List<Comment> Comments { get; set; }
}

// 标签
public class Tag
{
    public int Id { get; set; }
    public string Name { get; set; }            // 显示名称
    public string Slug { get; set; }            // URL slug
    public int ArticleCount { get; set; }       // 缓存文章数
}

// 媒体
public class Media
{
    public int Id { get; set; }
    public string FileName { get; set; }         // 文件名
    public string OriginalName { get; set; }     // 原文件名
    public string Url { get; set; }              // 访问路径
    public string MimeType { get; set; }        // MIME 类型
    public long FileSize { get; set; }          // 文件大小
    public int Width { get; set; }              // 图片宽度
    public int Height { get; set; }             // 图片高度
    public DateTime CreatedAt { get; set; }
}

// 留言
public class Comment
{
    public int Id { get; set; }
    public string AuthorName { get; set; }      // 留言者昵称
    public string AuthorEmail { get; set; }     // 留言者邮箱
    public string Content { get; set; }         // 留言内容
    public bool IsApproved { get; set; }        // 审核状态
    public int? ArticleId { get; set; }         // 关联文章
    public Article? Article { get; set; }
    public DateTime CreatedAt { get; set; }
}

// 页面内容（首页/关于页等）
public class PageContent
{
    public int Id { get; set; }
    public string PageKey { get; set; }         // home/about/projects
    public string Title { get; set; }
    public string Content { get; set; }         // JSON 配置
    public DateTime UpdatedAt { get; set; }
}
```

## 五、安全设计

### 5.1 认证方案

| 方案 | 适用场景 |
|-----|---------|
| JWT Bearer Token | API 调用 |
| HttpOnly Cookie | Web 前端会话 |

### 5.2 密码安全

- BCrypt 哈希（cost factor 12）
- 密码强度：8位以上，含大小写和数字

### 5.3 API 安全

| 措施 | 说明 |
|-----|-----|
| 速率限制 | 100 req/min（未认证），1000 req/min（已认证） |
| CORS | 仅允许指定域名 |
| 输入校验 | 请求参数校验 |
| SQL 注入防护 | EF Core 参数化查询 |
| XSS 防护 | 内容转义 |

### 5.4 Git 安全

- 使用 GitHub Personal Access Token
- Token 仅限仓库写入权限
- Token 存储于环境变量
