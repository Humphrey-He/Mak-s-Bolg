# 博客自研 CMS 功能排期

## 一、总体排期概览

| 阶段 | 周期 | 目标 |
|-----|-----|-----|
| Phase 0：准备期 | 1 周 | 理顺内容结构和发布机制 |
| Phase 1：CMS MVP | 3-4 周 | 核心写作发布链路 |
| Phase 2：后台增强 | 3-4 周 | 媒体库/标签/预览/SEO |
| Phase 3：Rust 引擎 | 3-5 周 | 内容工具链 CLI |
| Phase 4：生产稳定化 | 1-2 周 | 部署上线 |

**总工期：约 11-16 周（渐进式）**

---

## 二、Phase 0：准备期（第 1 周）

**目标：理顺内容结构，不影响现有博客**

| 日期 | 任务 | 功能点 | 验收标准 |
|-----|-----|-------|---------|
| Day 1-2 | 统一 MDX frontmatter | 固定 schema | 所有文章符合新 schema |
| Day 2-3 | 校验脚本 | Rust validate CLI | 可检测格式错误 |
| Day 3-4 | slug 规范化 | 统一命名规则 | 无重复/非法 slug |
| Day 4-5 | Cloudflare 稳定化 | 部署流水线 | push 后自动构建 |
| Day 5 | Tina 临时方案 | 继续使用 Tina | 不阻断写作 |

**阶段验收：**
- [ ] MDX schema 统一
- [ ] 校验工具可用

## 十、风险与对策

| 风险 | 影响 | 对策 |
|-----|-----|-----|
| Git 操作冲突 | 高 | 任务队列 + 锁 + retry |

| 部署复杂度 | 中 | Docker 容器化 |
