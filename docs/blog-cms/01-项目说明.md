# 博客自研 CMS 项目说明

## 一、项目背景

### 1.1 现状分析

当前博客技术栈：
- **前台**：Next.js 静态导出 + Cloudflare Pages
- **内容**：MDX 格式存储于 Git 仓库
- **内容管理**：TinaCMS（Git-backed CMS）

TinaCMS 的局限性：
- 依赖第三方服务（Tina Cloud）
- 分支索引偶发故障
- 自定义能力受限
- 团队协作功能有限

### 1.2 建设目标

构建一套自有的博客内容管理系统，实现：
- 独立可控的内容管理能力
- 高效的内容创作与发布体验
- 可扩展的架构设计
- 技术作品展示价值

### 1.3 建设原则

1. **最小可用**：快速上线 MVP，持续迭代
2. **技术变现**：C# 练手 + Rust 内容引擎形成技术亮点
3. **渐进迁移**：不影响现有博客运行，逐步替代 TinaCMS

---

## 二、项目范围

### 2.1 建设内容

| 类别 | 内容 |
|-----|-----|
| C# CMS 后台 | 管理员认证、文章管理、标签管理、媒体库、内容发布 |
| Rust 内容引擎 | Markdown 解析、内容校验、搜索索引、SEO 工具 |
| 前台适配 | 现有博客与新 CMS 的数据对接 |

### 2.2 非建设内容

- 多用户权限系统（第一阶段）
- 评论系统
- 访问统计
- 付费功能
