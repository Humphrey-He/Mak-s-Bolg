# 博客自研 CMS 项目说明

## 一、项目背景

### 1.1 现状分析

当前博客技术栈：
- **前台**：Next.js 静态导出 + Cloudflare Pages
- **内容**：MDX 格式存储于 Git 仓库
- **内容管理**：TinaCMS（Git-backed CMS）

TinaCMS 的局限性：
- 依赖第三方服务（Tina Cloud）
- 分支索引偶发故障
- 自定义能力受限
- 团队协作功能有限

### 1.2 建设目标

构建一套自有的博客内容管理系统，实现：
- 独立可控的内容管理能力
- 高效的内容创作与发布体验
- 可扩展的架构设计
- 技术作品展示价值

### 1.3 建设原则

1. **最小可用**：快速上线 MVP，持续迭代
2. **技术变现**：C# 练手 + Rust 内容引擎形成技术亮点
3. **渐进迁移**：不影响现有博客运行，逐步替代 TinaCMS

## 二、博客业务需求分析

### 2.1 内容类型

| 内容类型 | 说明 | 示例 |
|---------|-----|-----|
| 技术文章 | 博客核心内容，含代码和数学公式 | W-TinyLFU 缓存算法详解 |
| 项目展示 | 独立项目/作品介绍 | API 网关项目 |
| 读书笔记 | 书籍阅读记录与思考 | - |
| 论文解读 | 学术论文笔记 | - |

### 2.2 文章元数据

根据现有博客数据结构，文章包含：

```yaml
title: 文章标题
description: 文章摘要
date: 发布日期 (YYYY-MM-DD)
tag: 标签分类 (如 "Go / Cache")
readTime: 阅读时间 (如 "15 min")
top: 是否置顶 (boolean)
featured: 是否精选 (boolean)
```

### 2.3 内容特性

| 特性 | 说明 |
|-----|-----|
| Markdown/MDX | 支持 Markdown 语法 |
| 代码高亮 | highlight.js 语法高亮 |
| LaTeX 数学公式 | KaTeX 渲染（行内 $...$，行块 $$...$$） |
| GFM 支持 | 表格、任务列表、删除线等 |
| 目录导航 | 文章侧边目录自动提取 |
| 阅读进度 | 文章阅读进度条 |

### 2.4 前台功能需求

| 模块 | 功能描述 |
|-----|---------|
| 首页 | Hero + 文章流 + 项目展示 |
| 文章列表 | 轮播 Top 5 + 全部文章分页 |
| 文章详情 | 正文渲染 + 目录 + 相关文章 |
| 项目列表 | 项目卡片展示 |
| 项目详情 | 项目详情页 |
| 搜索 | 标签筛选 + 关键词搜索 |

## 五、建设内容

### 5.1 C# CMS 后台

| 模块 | 功能点 |
|-----|-------|
| 认证管理 | 登录/登出/JWT/会话管理 |
| 文章管理 | CRUD/草稿/发布/置顶/精选 |
| 标签管理 | 标签 CRUD/文章关联 |
| 媒体库 | 图片上传/管理/裁剪/插入 |
| 页面管理 | 首页/关于页/项目页内容 |
| 留言管理 | 留言审核/回复/删除 |
| SEO 设置 | Meta/Sitemap/RSS |
| 数据统计 | PV/UV/文章排行/标签统计 |

### 5.2 Rust 内容引擎

| 模块 | 功能点 |
|-----|-------|
| MDX 解析器 | Frontmatter 提取/内容校验 |
| 全文搜索 | Tantivy 索引/分词/搜索 |
| 内容校验 | 死链检测/格式校验/完整性检查 |
| SEO 工具 | Sitemap 生成/RSS 生成 |
| 数学公式 | LaTeX 语法校验 |

### 5.3 非建设内容（后续版本）

- 多用户权限系统
- 付费阅读
- 邮件订阅推送
- 微信/公众号同步
- AI 写作辅助
