# Mak's Blog CMS 文档编辑与发布指南

## 概述

Mak's Blog CMS 是一个 Git-backed 内容发布系统，使用 MDX/Markdown 作为内容格式，支持 Cloudflare Pages 部署。

---

## 1. 文档编辑与存储

### 1.1 编辑器架构

文章编辑器 (`ArticleEditor.tsx`) 提供以下功能：

| 功能 | 说明 |
|------|------|
| 标题编辑 | 输入文章标题 |
| Slug 编辑 | 文章 URL 别名，支持复制 |
| 描述编辑 | 文章摘要说明 |
| 内容编辑 | Markdown 编辑器，支持三种模式 |
| 标签管理 | 自动完成标签输入 |
| 封面图片 | 从媒体库选择 |

### 1.2 编辑器模式

| 模式 | 说明 |
|------|------|
| **编辑模式** | 纯 Markdown 编辑 |
| **预览模式** | Markdown 实时渲染预览 |
| **分屏模式** | 左编辑右预览同步滚动 |

### 1.3 内容存储格式

文章以 MDX 格式存储到 Git 仓库，格式如下：

```markdown
---
title: "文章标题"
description: "文章描述"
date: "2026-05-09"
tags: ["tag1", "tag2"]
---

# 文章标题

正文内容...
```

### 1.4 存储位置

- **开发环境**: `src/BlogCMS.Api/data/articles/` (SQLite 关联的本地文件)
- **生产环境**: Git 仓库的 `content/articles/` 目录

### 1.5 自动保存

- 编辑后 3 秒无操作自动保存草稿
- 页面离开时如有未保存更改会提示确认
- 键盘快捷键: `Ctrl+S` 手动保存

## 2. 图片资源管理

### 2.1 媒体库功能

媒体库 (`MediaLibrary.tsx`) 管理所有图片资源：

| 功能 | 说明 |
|------|------|
| 上传图片 | 拖拽或点击上传 |
| 预览图片 | 网格视图展示 |
| 复制 URL | 一键复制图片链接 |
| 删除图片 | 确认后删除 |

### 2.2 图片插入流程

1. 在文章编辑器中点击插入图片按钮
2. 从媒体库选择已有图片或上传新图片
3. 图片以 Markdown 格式插入到光标位置

### 2.3 图片使用方式

编辑器支持两种图片引用方式：

```markdown
# 媒体库图片（推荐）
![图片描述](/media/image-name.png)

# 外部 URL 图片
![图片描述](https://example.com/image.png)
```

### 2.4 媒体库 API

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/api/media` | 获取媒体列表 |
| POST | `/api/media/upload` | 上传新图片 |
| DELETE | `/api/media/{id}` | 删除图片 |

### 2.5 存储位置

- **开发环境**: `src/BlogCMS.Api/data/media/`
- **生产环境**: Cloudflare R2 存储桶或 Git 仓库 `public/media/`

## 3. 文章发布

### 3.1 发布流程

```
保存草稿 → 内容校验 → Git 提交 → CI/CD 构建 → 部署上线
```

### 3.2 发布状态

| 状态 | 说明 | 颜色 |
|------|------|------|
| `草稿 (Draft)` | 未发布的内容 | 灰色 |
| `发布中 (Publishing)` | 正在部署 | 蓝色 |
| `已发布 (Published)` | 已上线 | 绿色 |
| `发布失败 (Failed)` | 部署出错 | 红色 |

### 3.3 发布校验

发布前系统会检查以下项目：

| 检查项 | 级别 | 说明 |
|--------|------|------|
| 标题 | 错误 | 必须填写，否则阻止发布 |
| Slug | 错误 | 必须填写，否则阻止发布 |
| 内容 | 错误 | 必须有内容，否则阻止发布 |
| 描述 | 警告 | 建议 50 字符以上 |
| 标签 | 警告 | 建议填写标签 |

### 3.4 发布记录

发布记录页面 (`PublishRecords.tsx`) 显示：

- Commit SHA
- 构建状态
- 发布时间
- 错误信息（如果失败）

### 3.5 发布 API

| 方法 | 端点 | 说明 |
|------|------|------|
| POST | `/api/articles/{id}/publish` | 发布文章 |
| GET | `/api/jobs` | 获取发布任务列表 |
| GET | `/api/jobs/{id}` | 获取单个任务状态 |

### 3.6 Git 工作流

1. 用户点击发布按钮
2. 后端更新文章状态为 `Publishing`
3. 将 MDX 文件 commit 到 Git
4. Push 到远程仓库触发 Cloudflare Pages 构建
5. 轮询 CI 状态直到完成
6. 更新文章状态为 `Published` 或 `Failed`

## 4. 导入导出功能

### 4.1 支持格式

| 格式 | 导入 | 导出 |
|------|------|------|
| Markdown (.md/.mdx) | ✅ | ✅ |
| Word (.docx) | ✅ | ✅ |
| LaTeX (.tex) | ❌ | ✅ |

### 4.2 导入流程

1. 点击导入按钮
2. 拖拽或选择文件
3. 系统解析 frontmatter 和正文
4. 自动填充到表单各字段

### 4.3 导出流程

1. 点击导出按钮
2. 选择导出格式
3. 浏览器自动下载文件

## 7. 多语言支持

系统支持三种语言：

| 语言 | 代码 | 说明 |
|------|------|------|
| 中文 | `zh-CN` | 默认语言 |
| 英文 | `en-US` | English |
| 日文 | `ja-JP` | 日本語 |

语言切换在设置页面或顶部导航。
