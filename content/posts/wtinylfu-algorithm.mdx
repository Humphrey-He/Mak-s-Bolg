## 背景

在缓存系统中，如何高效地淘汰低价值数据、保留热点数据是一个核心问题。W-TinyLFU（Window TinyLFU）是一种结合了 **L**east **R**ecently **U**sed（最近最少使用）和 **F**requency **L**east **F**requently **U**sed（最不频繁使用）优点的准入策略。

## 核心公式

### 1. 布隆过滤器（Bloom Filter）

布隆过滤器用于快速判断一个 key 是否曾经被访问过。其假阳性率（False Positive Rate）为：

$$
p = (1 - e^\bgroup -kn/m\egroup)^k
$$

其中：
- $n$ — 已插入元素数量
- $m$ — 位数组长度
- $k$ — 哈希函数数量

最优哈希函数数量为：

$$
k_\bgroup opt\egroup = \frac\bgroup m\egroup\bgroup n\egroup \ln 2
$$

### 2. 频率计数（Frequency Counter）

TinyLFU 使用 **Count-Min Sketch** 来估计访问频率：

$$
f_\bgroup ij\egroup = f_\bgroup ij\egroup + 1 \quad \text\bgroup for all \egroup j \in h_i(x)
$$

其中 $h_i(x)$ 是 key $x$ 的第 $i$ 个哈希值对应的计数器位置。

### 3. W-TinyLFU 窗口

W-TinyLFU 将缓存分为两个区域：
- **Window Cache**：大小为总容量的 $1\%$
- **Main Cache**：剩余 $99\%$

$$
C_\bgroup total\egroup = C_\bgroup window\egroup + C_\bgroup main\egroup
$$

$$
C_\bgroup window\egroup = 0.01 \times C_\bgroup total\egroup
$$

### 4. 准入评分（Admission Score）

当一个新 entry 需要进入 Main Cache 时，计算其准入评分：

$$
S_\bgroup new\egroup = \frac\bgroup f_\bgroup new\egroup \egroup\bgroup \max_\bgroup old \in victim\egroup \egroup
$$

如果 $S_\bgroup new\egroup > S_\bgroup old\egroup$，则新 entry 准入，得分最低的 entry 被淘汰。

## 算法流程

```go
func (w *W TinyLFU) Admit(key string) bool {
    // 1. 计算新 key 的频率
    freq := w sketch.Estimate(key)

    // 2. 找到 Main Cache 中得分最低的 entry
    victim, victimScore := w.mainCache.EvictCandidate()

    // 3. 比较准入评分
    if freq > victimScore {
        w.mainCache.Put(key)
        return true
    }
    return false
}
```

| 数据集 | 命中率 | 内存效率 |

## 总结

W-TinyLFU 通过布隆过滤器 + Count-Min Sketch 的组合，实现了 $O(1)$ 时间复杂度的频率估计，同时通过滑动窗口机制保护了短期热点数据。

$$
\boxed\bgroup \text\bgroup Hit Rate\egroup \approx 1 - \frac\bgroup 1\egroup\bgroup 1 + \alpha \cdot \text\bgroup Zipf\egroup_\bgroup \lambda\egroup \egroup \egroup
$$
