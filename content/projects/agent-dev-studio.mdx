## 项目背景

Agent Dev Studio 关注的不只是单次对话，而是把 Agent 真正做成可开发、可观测、可迭代的工程系统。

## 核心设计

### 工具调用

支持函数调用与外部工具接入，扩展 Agent 的行动能力。

### 工作流编排

将任务拆解、执行和回收组织成稳定流程。

### 记忆与评测

通过向量检索、记忆管理和评测链路支持持续优化。
