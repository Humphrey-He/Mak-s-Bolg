TinaCMS Admin

/admin 还没有切换到 Tina 登录页面

当前部署缺少 Tina 生产环境变量，所以构建系统保留了这个 fallback 页面。 站点前台可以继续上线，但 Tina 可视化编辑后台还没有真正启用。

当 Tina 配置完整后，/admin/ 会被 Tina 的真实后台覆盖， 你会看到 TinaCloud 登录页，而不是这张说明页。

Cloudflare Pages 需要的变量

  • NEXT_PUBLIC_TINA_CLIENT_ID
  • TINA_TOKEN
  • NEXT_PUBLIC_TINA_BRANCH
  • NEXT_PUBLIC_SITE_URL

启用成功后的预期

  • 部署日志里出现「PASS: Tina admin built」
  • /admin/ 打开 TinaCloud 登录页
  • 登录后可编辑 content/posts 和 content/projects
